# 小红书自动发布系统 - 安装指南

云端运行请看 [cloud-architecture.md](cloud-architecture.md)。不要再下载 Mac 二进制，不要把 MCP 指到 Mac 的 localhost，也不要安装 crontab。下面若与那份文档冲突，以那份文档为准。

## 系统要求

- macOS 10.15+ 或 Linux
- Python 3.8+
- 2GB 可用磁盘空间

## 安装步骤

### 1. 安装 Homebrew

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### 2. 安装 Python3 和依赖

```bash
brew install python3 ffmpeg
pip3 install -r requirements.txt
```

### 3. 编译 MCP

不要下载上游 release 二进制，也不要再放一份 Mac 二进制。在本仓库所在的同一台云主机上：

```bash
./scripts/build_mcp.sh
```

这会从 https://github.com/alex22222/xiaohongshu-mcp 取出提交 `bb6fa2e208719ee634fec37881be29d3aa4699b3` 并在本地编译。产物留在 `runtime/`，不要提交。

### 4. 登录小红书

登录只在长期使用的那台云主机上做，由所有者扫码。不要把 cookie 拷进仓库。步骤在 [cloud-architecture.md](cloud-architecture.md)。未扫码之前，`python3 scripts/health_check.py --login-status` 里的 `is_logged_in` 会是 false。

### 5. 配置项目

```bash
# 复制配置模板
cp config/config.json.example config/config.json

# 编辑配置
nano config/config.json
```

修改以下内容：
- `data_sources`: 配置Excel文件路径和图片路径
- `mcp`: 确认MCP工具路径

### 6. 准备数据

```bash
# 创建数据目录
mkdir -p data

# 复制Excel文件到配置的路径
# 复制图片到配置的image_dir
```

### 7. 测试运行

只检查状态，不发笔记：

```bash
python3 src/xiaohongshu_pause.py status
./scripts/start_mcp.sh
python3 scripts/health_check.py
python3 scripts/health_check.py --login-status
```

### 8. 定时任务

不要添加 crontab。旧的 `0 8,14,20` 任务保持暂停。

## 常见问题

### Q1: 提示"未找到MCP工具"

```bash
# 检查文件是否存在
ls -la mcp/

# 设置执行权限
chmod +x mcp/xiaohongshu-*
```

### Q2: 登录失败

```bash
# 删除旧cookie
rm ~/.xhs-mcp/cookies.json

# 重新登录
./mcp/xiaohongshu-login-darwin-amd64
```

### Q3: Excel读取失败

```bash
# 安装openpyxl
pip3 install openpyxl

# 检查Excel文件格式
```

## 卸载

```bash
# 停止定时任务
crontab -e
# 删除相关行

# 删除项目目录
rm -rf /path/to/xiaohongshu-auto-publisher
```
