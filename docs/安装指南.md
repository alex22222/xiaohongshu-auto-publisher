# 小红书自动发布系统 - 安装指南

## 系统要求

- macOS 10.15+ 或 Linux
- Python 3.8+
- 2GB 可用磁盘空间

## 安装步骤

### 1. 安装 Homebrew

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### 2. 安装 Python3 和依赖

```bash
brew install python3 ffmpeg
pip3 install -r requirements.txt
```

### 3. 下载MCP工具

从Release页面下载对应系统的MCP工具：

```bash
# 创建目录
mkdir -p mcp

# 下载（根据系统选择）
# macOS Apple Silicon
curl -L -o mcp/xiaohongshu-mcp-darwin-arm64 "https://github.com/yourrepo/releases/download/v1.0/xiaohongshu-mcp-darwin-arm64"

# macOS Intel
curl -L -o mcp/xiaohongshu-mcp-darwin-amd64 "https://github.com/yourrepo/releases/download/v1.0/xiaohongshu-mcp-darwin-amd64"

# 设置权限
chmod +x mcp/xiaohongshu-mcp-*
```

### 4. 登录小红书

```bash
# 运行登录工具
./mcp/xiaohongshu-login-darwin-amd64

# 按提示扫码登录
# 登录成功后会生成 cookies.json
```

### 5. 配置项目

```bash
# 复制配置模板
cp config/config.json.example config/config.json

# 编辑配置
nano config/config.json
```

修改以下内容：
- `data_sources`: 配置Excel文件路径和图片路径
- `mcp`: 确认MCP工具路径

### 6. 准备数据

```bash
# 创建数据目录
mkdir -p data

# 复制Excel文件到配置的路径
# 复制图片到配置的image_dir
```

### 7. 测试运行

```bash
# 测试发布（暂停状态下不会实际发布）
python3 src/xiaohongshu_pause.py status

# 运行一次
python3 src/xiaohongshu_full_auto_system_v3_complete.py
```

### 8. 设置定时任务

```bash
crontab -e
```

添加：
```
0 8,14,20 * * * cd /path/to/xiaohongshu-auto-publisher && python3 src/xiaohongshu_full_auto_system_v3_complete.py >> logs/publisher.log 2>&1
```

## 常见问题

### Q1: 提示"未找到MCP工具"

```bash
# 检查文件是否存在
ls -la mcp/

# 设置执行权限
chmod +x mcp/xiaohongshu-*
```

### Q2: 登录失败

```bash
# 删除旧cookie
rm ~/.xhs-mcp/cookies.json

# 重新登录
./mcp/xiaohongshu-login-darwin-amd64
```

### Q3: Excel读取失败

```bash
# 安装openpyxl
pip3 install openpyxl

# 检查Excel文件格式
```

## 卸载

```bash
# 停止定时任务
crontab -e
# 删除相关行

# 删除项目目录
rm -rf /path/to/xiaohongshu-auto-publisher
```
