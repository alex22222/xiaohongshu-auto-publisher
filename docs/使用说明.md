# 小红书自动发布系统 - 使用说明

## 基本使用

### 手动发布

```bash
# 立即发布一次
python3 src/xiaohongshu_full_auto_system_v3_complete.py
```

### 暂停/恢复发布

```bash
# 暂停2天
python3 src/xiaohongshu_pause.py days --days 2

# 暂停到指定日期
python3 src/xiaohongshu_pause.py until --date 2024-12-31

# 恢复发布
python3 src/xiaohongshu_pause.py resume

# 查看状态
python3 src/xiaohongshu_pause.py status
```

### 评论管理

```bash
# 检查评论
python3 src/run_comment_check.py

# 运行评论回复系统
python3 src/xiaohongshu_comment_reply_system.py
```

## 配置文件详解

### config.json

```json
{
  "data_sources": {
    "source_name": {
      "name": "显示名称",
      "file": "Excel文件路径",
      "image_prefix": "图片前缀",
      "image_dir": "图片目录"
    }
  }
}
```

### Excel格式

| 列名 | 说明 |
|------|------|
| 序号 | 文章编号 |
| 文章标题 | 文章标题 |
| 文章链接 | 原文链接（可选） |
| 分类 | 文章分类 |
| 配图路径 | 图片文件名 |

## 日志查看

```bash
# 查看发布日志
tail -f logs/publisher.log

# 查看评论日志
tail -f logs/comment.log
```

## 数据备份

```bash
# 备份数据
cp -r data/ data_backup_$(date +%Y%m%d)/

# 备份cookie
cp ~/.xhs-mcp/cookies.json cookies_backup.json
```

## 高级功能

### 自定义发布时间

编辑 `crontab`：

```bash
crontab -e
```

格式：
```
# 每2小时发布一次
0 */2 * * * cd /path/to/project && python3 src/xiaohongshu_full_auto_system_v3_complete.py

# 工作日每天10点发布
0 10 * * 1-5 cd /path/to/project && python3 src/xiaohongshu_full_auto_system_v3_complete.py
```

### 多账号支持

创建多个配置文件：

```bash
cp config/config.json config/config_account2.json
# 修改配置后运行
python3 src/xiaohongshu_full_auto_system_v3_complete.py --config config/config_account2.json
```

## 故障排查

### 发布失败

1. 检查网络连接
2. 检查cookie是否过期
3. 查看日志文件

### 定时任务不执行

```bash
# 检查cron服务
sudo launchctl list | grep cron

# 检查权限
ls -la src/xiaohongshu_full_auto_system_v3_complete.py

# 手动测试
cd /path/to/project && python3 src/xiaohongshu_full_auto_system_v3_complete.py
```

## 安全建议

1. 定期更换小红书密码
2. 不要将cookie文件分享给他人
3. 使用强密码保护服务器
4. 定期检查发布日志
