# 小红书自动发布系统 - 使用说明

发布已经关掉。不要按下面的旧命令去发笔记或装 crontab。现行步骤在 [cloud-architecture.md](cloud-architecture.md) 和仓库根目录的 README：只做健康检查和登录状态。旧的 8:00 / 14:00 / 20:00 定时任务继续暂停。

## 基本使用

### 手动发布

不要执行发布。下面这条会直接退出，不会发笔记：

```bash
python3 src/xiaohongshu_full_auto_system_v3_complete.py
```

### 暂停/恢复发布

```bash
# 暂停2天
python3 src/xiaohongshu_pause.py days --days 2

# 暂停到指定日期
python3 src/xiaohongshu_pause.py until --date 2024-12-31

# 恢复发布
python3 src/xiaohongshu_pause.py resume

# 查看状态
python3 src/xiaohongshu_pause.py status
```

### 评论管理

```bash
# 检查评论
python3 src/run_comment_check.py

# 运行评论回复系统
python3 src/xiaohongshu_comment_reply_system.py
```

## 配置文件详解

### config.json

```json
{
  "data_sources": {
    "source_name": {
      "name": "显示名称",
      "file": "Excel文件路径",
      "image_prefix": "图片前缀",
      "image_dir": "图片目录"
    }
  }
}
```

### Excel格式

| 列名 | 说明 |
|------|------|
| 序号 | 文章编号 |
| 文章标题 | 文章标题 |
| 文章链接 | 原文链接（可选） |
| 分类 | 文章分类 |
| 配图路径 | 图片文件名 |

```bash

cp ~/.xhs-mcp/cookies.json cookies_backup.json
```

## 高级功能

### 自定义发布时间

不要安装 crontab。旧的一天三次任务曾经在大约 26 分钟里发出 3 篇，必须继续暂停。以后的频率只写在 `config/config.json.example`：每天最多 1 篇，间隔至少 24 小时，仅白天。审过的草稿也不会自动发。

### 多账号支持

创建多个配置文件：

```bash
cp config/config.json config/config_account2.json
# 修改配置后运行
python3 src/xiaohongshu_full_auto_system_v3_complete.py --config config/config_account2.json
```

## 故障排查

### 发布失败

1. 检查网络连接
2. 检查cookie是否过期
3. 查看日志文件

### 定时任务不执行

```bash
# 检查cron服务
sudo launchctl list | grep cron

# 检查权限
ls -la src/xiaohongshu_full_auto_system_v3_complete.py

# 手动测试
cd /path/to/project && python3 src/xiaohongshu_full_auto_system_v3_complete.py
```

## 安全建议

1. 定期更换小红书密码
2. 不要将cookie文件分享给他人
3. 使用强密码保护服务器
4. 定期检查发布日志
